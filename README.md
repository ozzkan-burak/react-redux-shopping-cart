# Classic React-Redux Shopping Cart

> 🏛️ **ARCHIVED PROJECT (Legacy Reference)**
>
> This repository is preserved to demonstrate **Classic Redux Patterns** (Connect HOC, Switch-Case Reducers, Manual Action Creators) used before the adoption of Redux Toolkit.
>
> **Why is this here?**
> Even though I use **Redux Toolkit** and **Context API** in modern projects, this codebase reflects my strong grasp of:
> * Fundamental Flux Architecture principles.
> * Immutable state management patterns.
> * Component lifecycle optimization in older React versions.
